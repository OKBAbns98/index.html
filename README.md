# English Arena A free practice site for IELTS preparation and general English. It runs as a single static page: no build step, no server and no dependencies. **Live site:** `https://.github.io//` (replace with your own address once GitHub Pages is on) > English Arena is an independent practice site. It is not affiliated with, or endorsed by, the IELTS partners. IELTS is a registered trademark of its owners. For official test information, visit [ielts.org](https://ielts.org). ## Features **Scoreboard** - Set your latest band (0 to 9, half bands) for Listening, Reading, Writing and Speaking. - The overall band is calculated using IELTS rounding. - Set a target band and see which skills still need work. **Practice room** - **Reading:** two original passages with True/False/Not given and multiple-choice questions, a passage highlighter and a best score for each passage. - **Listening:** a recording read aloud by the browser, four questions and a show/hide transcript. - **Vocabulary:** academic word flashcards that remember which words you have learned. - **Writing (Task 2):** random essay questions, a 40-minute timer and a live word count toward 250. - **Chart writing (Task 1):** a bar chart question, a 20-minute timer and a word count toward 150. - **Speaking (Part 2):** cue cards with a one-minute preparation timer and a two-minute speaking timer, plus a box for your transcript. - **Exam mode:** hides everything except the practice tabs. **AI evaluation** (see the note on hosting below) - Writing, chart writing and speaking responses get estimated bands for each criterion, strengths, priority fixes and an improved sentence. - Reading and listening answers get explanations that point to the evidence in the passage or transcript. - Speaking can be dictated in supported browsers. **English practice** - Four grammar lessons (present perfect and past simple, conditionals, relative clauses, articles) with instant feedback. - A 12-question level test with an estimated CEFR level and a rough IELTS range. **Progress by module** - A summary of reading and listening results, draft lengths and vocabulary learned. All progress, scores and drafts are saved in the visitor's own browser using `localStorage`. Nothing is sent to a server, and there are no accounts. ## Run it locally 1. Download `index.html`. 2.
